1. Touchless AI Vision Core

MediaPipe Hands ประมวลผลจุดพิกัดมือ 21 ข้อต่อแบบ On-Device บนเว็บเบราว์เซอร์ จำแนกท่าทาง Pinch, Point, Fist และ Tilt โดยไม่ส่งข้อมูลภาพออกจากเครื่อง เพื่อความปลอดภัยและเป็นส่วนตัว 100%

2. 3D WebXR & Zero-GC Engine

สร้างชิ้นงาน 3D ด้วย A-Frame 1.4.2 และ Three.js PBR Shaders พร้อมการออกแบบวงรอบคำนวณแบบ Zero-GC Loop Engineering เพื่อรักษาความเร็วระดับ 60 FPS ต่อเนื่องบนทุกอุปกรณ์

3. Web Audio Acoustic Synthesizer

สังเคราะห์คลื่นเสียงฟิสิกส์สดผ่าน Web Audio API อัตโนมัติ (เสียงหน้าสัมผัสรีเลย์, เสียงโพรบปิ๊บ, เสียงฮัมความถี่มอเตอร์ และเสียงฟองน้ำ) โดยไม่ต้องดาวน์โหลดไฟล์เสียงภายนอก
