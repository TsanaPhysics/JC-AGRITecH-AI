# คู่มือการเชื่อมต่อระบบฐานข้อมูล Edge xAIoT เข้ากับ Google Sheets (Real-time Cloud Sync)

ระบบเชื่อมต่อนี้ได้รับการออกแบบสถาปัตยกรรมแบบ **Hybrid Local-First**:
* **บนเว็บเซิร์ฟเวอร์:** จัดเก็บข้อมูลลง **SQLite3 (`leqs_xai.db`)** และสำรองเป็น **Flat-file JSON (`participants.json`)** เป็นหลัก เพื่อความรวดเร็วและปลอดภัยสูงสุด
* **บน Google Sheets:** ทำหน้าที่เป็น **One-Way Realtime Mirror** ให้คณาจารย์และทีมงาน LEQs สามารถเปิดดูรายชื่อผู้สมัคร เบอร์โทรศัพท์ และแทร็กโครงงานผ่าน Google Sheets บนมือถือหรือคอมพิวเตอร์ได้ทันทีโดยไม่ต้องล็อกอินเข้าระบบหลังบ้าน

---

## ขั้นตอนการติดตั้ง (ใช้เวลาประมาณ 2 นาที)

### ขั้นตอนที่ 1: เตรียม Google Sheet
1. เปิด [Google Sheets](https://sheets.new) และสร้างแผ่นงานใหม่ (ตั้งชื่อไฟล์ตามต้องการ เช่น `ผู้ลงทะเบียน_Edge_xAIoT_2026`)
2. คัดลอกลิงก์ URL ของ Google Sheet ในแถบ Address Bar ของเบราว์เซอร์เก็บไว้

### ขั้นตอนที่ 2: ติดตั้งสคริปต์ Apps Script
1. ในหน้า Google Sheet ให้คลิกเมนู **"ส่วนขยาย" (Extensions) > "Apps Script"**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกทั้งหมด
3. เปิดไฟล์ `google_sheets_script/Code.gs` ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางแทนที่
4. กดปุ่ม **"บันทึกโครงการ"** (ไอคอนรูปแผ่นดิสก์ 💾)

### ขั้นตอนที่ 3: ทำให้ใช้งานได้ (Deploy as Web App)
1. กดปุ่มสีน้ำเงินมุมขวาบน **"การทำให้ใช้งานได้" (Deploy) > "การทำให้ใช้งานได้ใหม่" (New deployment)**
2. คลิกไอคอนรูปเฟือง ⚙️ ด้านซ้าย แล้วเลือก **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   * **คำอธิบาย (Description):** `Edge xAI : 4DAgriEnvi Sync Webhook`
   * **ดำเนินการในฐานะ (Execute as):** `ฉัน (อีเมลของคุณ)`
   * **ผู้มีสิทธิ์เข้าถึง (Who has access):** **`ทุกคน (Anyone)`** *(สำคัญมาก เพื่อให้เซิร์ฟเวอร์ PHP ยิงข้อมูลเข้ามาได้)*
4. กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
   *(หาก Google ขอสิทธิ์อนุญาตการเข้าถึง ให้กด `Authorize access` > เลือกบัญชีของคุณ > กด `Advanced` > กด `Go to ... (unsafe)` > กด `Allow`)*
5. คัดลอก **"URL ของเว็บแอป" (Web app URL)** ที่ขึ้นต้นด้วย:  
   `https://script.google.com/macros/s/AKfycb.../exec`

### ขั้นตอนที่ 4: เชื่อมต่อในระบบ Admin Dashboard
1. เข้าสู่ระบบผู้ดูแลระบบของเว็บไซต์ที่:  
   `https://scicenter.rbru.ac.th/edge-xaiot-agrienvi/admin/`
2. ไปที่ตารางทำเนียบรายชื่อผู้ลงทะเบียน แล้วคลิกปุ่ม **"Google Sheets"**
3. สับสวิตช์ **"เปิดใช้งานระบบเชื่อมต่อ Google Sheets"**
4. วาง **Web app URL** และลิงก์ไฟล์ Google Sheet ลงในช่อง
5. กดปุ่ม **"บันทึกการตั้งค่า"**
6. กดปุ่ม **"ทดสอบการเชื่อมต่อ"** เพื่อตรวจสอบความถูกต้อง
7. กดปุ่ม **"Sync ข้อมูลทั้งหมดขึ้น Google Sheet"** เพื่อส่งรายชื่อที่มีอยู่ทั้งหมดขึ้นสู่ Google Sheet ทันที!

## คุณสมบัติเด่นของระบบ
1. **Real-time Auto-Append:** เมื่อมีผู้สมัครใหม่ผ่านหน้าเว็บ ข้อมูลจะถูกบันทึกลงใน Google Sheet ทันทีใน 0.5 วินาที
2. **Batch Sync / Re-sync:** หากต้องการอัปเดตสถานะการเช็คอิน หรือคะแนน Pre/Post Test สามารถกด Sync ทั้งหมดขึ้นไปทับได้ตลอดเวลา
3. **ป้องกันเบอร์โทรศัพท์หลุด 0 นำหน้า:** สคริปต์จะใส่ `'` หน้าเบอร์โทรให้อัตโนมัติ ทำให้เบอร์ `0937422654` ไม่กลายเป็น `937422654`
4. **ความปลอดภัย:** หาก Google ขัดข้องหรือเน็ตช้า จะมี Timeout 4 วินาที และไม่กระทบต่อการลงทะเบียนของผู้ใช้ในหน้าเว็บแน่นอน
