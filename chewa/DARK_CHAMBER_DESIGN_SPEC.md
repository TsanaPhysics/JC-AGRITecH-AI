# เอกสารการออกแบบวิศวกรรมโครงสร้างกล่องวัดแบบทึบแสง (Optical Dark Chamber 45°/0°)

**โครงการวิจัย** การพัฒนาชุดวิเคราะห์ปริมาณไนโตรเจนและฟอสฟอรัสในดินแบบพกพาด้วยหลักการสะท้อนแสงร่วมกับปัญญาประดิษฐ์  
**สัญญาเลขที่** 2251/2569 กองทุนวิจัย มหาวิทยาลัยราชภัฏรำไพพรรณี  
**หัวหน้าโครงการ** ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา  

---

## 1. บทนำและหลักการเชิงทัศนศาสตร์ (Optical Working Principle)

ในการตรวจวัดปริมาณธาตุอาหารในดินด้วยการวัดค่าสเปกตรัมการสะท้อนแสงแบบกระจาย (Diffuse Reflectance Spectrophotometry) ปัจจัยแวดล้อมที่ส่งผลกระทบต่อความถูกต้องของข้อมูลมากที่สุดคือ **ความผันผวนของแสงแวดล้อมภายนอก (Ambient Light Fluctuation)** และ **แสงสะท้อนหน้ากระจกเงา (Specular Glare Reflection)** 

เพื่อแก้ปัญหาดังกล่าว โครงสร้างกล่องวัดแบบทึบแสง (Optical Dark Chamber) นี้ได้รับการออกแบบขึ้นตามมาตรฐานสากล CIE 45°/0° Geometry โดยมีคุณสมบัติสำคัญดังนี้

1. **เรขาคณิตการตกกระทบและการรับแสง (45°/0° Geometry)** ลำแสงจากชุดไดโอดเปล่งแสง (LED Array) จะตกกระทบลงบนผิวหน้าดินทำมุม 45 องศา และช่องรับแสงของเซนเซอร์หรือเลนส์สมาร์ทโฟนจะวางอยู่ในแนวตั้งฉาก 0 องศา ซึ่งจะช่วยกำจัดการสะท้อนหน้าเรียบแบบกระจกเงา (Specular Reflection) ให้คงเหลือเฉพาะแสงสะท้อนแบบกระจายตัวที่เกิดจากอันตรกิริยาระหว่างแสงกับอนุภาคดินเท่านั้น
2. **ระยะทางทัศนศาสตร์คงที่ (Fixed Optical Working Distance)** กำหนดระยะห่างจากเลนส์รับแสงถึงระนาบผิวหน้าดินคงที่ 50 มิลลิเมตร ตลอดการตรวจวัด เพื่อรักษาขนาดพื้นที่ตรวจวัด (Field of View หรือ FOV) และความหนาแน่นฟลักซ์ส่องสว่างให้สม่ำเสมอทุกครั้ง
3. **การกำจัดแสงรั่วระดับเดซิเบลสูง (High Extinction Ratio)** ออกแบบแผ่นกั้นดักแสงแบบเขี้ยวซ้อนสองชั้น (Double-lip Labyrinth Seal) และขอบซีลยางโฟม EVA เพื่อให้มีอัตราการกำจัดแสงรบกวนสูงกว่าร้อยละ 99.94 แม้จะใช้งานกลางแจ้งภายใต้แสงแดดจัดมากกว่า 85,000 ลักซ์ โดยภายในกล่องมีค่าความสว่างต่ำกว่า 0.05 ลักซ์

## 3. สถาปัตยกรรมชิ้นส่วนแยกชิ้น (Modular Architectural Breakdown)

ระบบกล่องวัดทึบแสงถูกแบ่งออกเป็น 4 ชิ้นส่วนหลักที่สามารถพิมพ์ขึ้นรูปและประกอบเข้าด้วยกันอย่างแม่นยำ

### 3.1 ตัวกล่องหลัก (Main Housing Shell with Internal Baffle)
* ทำหน้าที่เป็นโครงสร้างรองรับหลัก ป้องกันแสงภายนอก และจัดระนาบทางเดินแสง
* ภายในหล่อขึ้นรูปด้วยกรวยคว่ำ (Conical Optical Baffle) ทำมุมเอียง 45 องศา จำนวน 6 ทิศทาง สำหรับเสียบหลอด Multi-wavelength LED ขนาด 5 มม. ได้แก่ 465, 525, 660, 720, 850 และ 940 นาโนเมตร
* ผนังห้องมืดด้านในได้รับการพ่นเคลือบด้วยสีดำด้านชนิดดูดกลืนแสงสูง (Ultra-flat Matt Black Coating) เพื่อให้ค่าการสะท้อนแสงภายในต่ำกว่าร้อยละ 1
* มีช่องสำหรับเดินสายไฟเชื่อมต่อระหว่างวงจร LED Driver กับบอร์ดไมโครคอนโทรลเลอร์ ESP32-S3

### 3.2 ลิ้นชักบรรจุตัวอย่างดิน (Sliding Soil Drawer with Labyrinth Seal)
* รางเลื่อนลิ้นชักด้านล่างช่วยให้สามารถสอดถาดตัวอย่างดินเข้าและออกได้อย่างรวดเร็วโดยไม่ต้องเปิดฝาบน
* เบ้าถาดบรรจุดินมีขนาดเส้นผ่านศูนย์กลาง 35 มม. ลึก 8 มม. ขอบบนมีบ่าสำหรับวางแผ่นเทียบสีขาวมาตรฐาน (White Reference Tile) เพื่อทำการ Calibration ฐานความสว่าง
* รอบขอบบานหน้าลิ้นชักมีระบบเขี้ยวดักแสงซ้อนสองชั้น (Double Labyrinth Seal) เมื่อดันลิ้นชักเข้าสุด เขี้ยวพลาสติกจะขบประสานกับร่องบนตัวกล่องหลัก ทำให้แสงแวดล้อมไม่สามารถเดินทางเป็นเส้นตรงหรือสะท้อนเล็ดลอดเข้ามาได้

### 3.3 ฝาบนพร้อมแท่นจับยึดสมาร์ทโฟน (Universal Smartphone Mount Lid)
* รางประกบสมาร์ทโฟนด้านบนกว้าง 78 มม. รองรับสมาร์ทโฟนหลากหลายรุ่น
* ตรงกลางแท่นมีกรวยเลนส์ (Lens Hood) ยื่นเข้าหาช่องรับแสง พร้อมร่องวงแหวนสำหรับใส่ **แผ่นปะเก็นยางโฟม EVA สีดำความหนาแน่นสูง (High-density Black EVA Gasket)**
* เมื่อวางสมาร์ทโฟนให้รูกล้องตรงกับตำแหน่ง กรอบยาง EVA จะแนบสนิทกับผิวกระจกเลนส์ของสมาร์ทโฟน 100% ขจัดแสงรั่วเข้าเลนส์ได้อย่างสิ้นเชิง
* ยึดฝาเข้ากับตัวกล่องหลักด้วยสกรู M3 จำนวน 4 ตัว

### 3.4 ฝาบนทางเลือกสำหรับโมดูลตรวจวัดออปติคอลฝังตัว (Alternative Sensor Plate)
* สำหรับการใช้งานแบบอุปกรณ์เดี่ยว (Standalone Portable Unit) ที่ไม่ใช้สมาร์ทโฟน
* มีรูเจาะเสายึดสำหรับบอร์ดกล้อง ESP32-CAM / ESP32-S3-Eye หรือบอร์ดเซนเซอร์สเปกตรัม AS7262 (6-Channel Visible Spectral Sensor) / AS7265x (18-Channel NIR Sensor)
* สามารถสลับเปลี่ยนใช้งานกับฝาสมาร์ทโฟนได้ทันทีโดยการขันสกรู M3

## 4. ข้อกำหนดพารามิเตอร์การพิมพ์ 3 มิติ (3D Printing Slicer Guidelines)

เพื่อให้ชิ้นงานที่พิมพ์ออกมามีคุณสมบัติทึบแสง 100% ไม่บิดงอ และทนต่อสภาพอากาศร้อนชื้นในการปฏิบัติงานภาคสนาม จำเป็นต้องตั้งค่าในโปรแกรม Slicer (เช่น PrusaSlicer, OrcaSlicer, Bambu Studio หรือ Cura) ดังนี้

| พารามิเตอร์ของ Slicer | ค่าที่แนะนำ | เหตุผลและความสำคัญ |
| :--- | :---: | :--- |
| ชนิดเส้นใยพลาสติก (Filament Type) | **Black PETG** | ทนต่อรังสี UV ความชื้น และความร้อนในแปลงทุเรียน ไม่เปราะหักเหมือน PLA |
| สีของเส้นใย | ดำทึบแสง (Solid Black) | มีสารเม็ดสีคาร์บอนแบล็คช่วยลดการส่องผ่านของแสง |
| ความหนาแน่นของเนื้อใน (Infill Density) | **100% Solid** (หรืออย่างน้อย 50% Gyroid) | ป้องกันแสงแดดความเข้มสูงทะลุผ่านช่องว่างภายในเนื้อพลาสติก |
| จำนวนรอบผนัง (Wall Perimeters) | **5 รอบ (Perimeters)** | ความหนาผนังสุทธิไม่น้อยกว่า 2.0 - 2.4 มม. เพื่อความทึบแสงเด็ดขาด |
| ความหนาชั้นพิมพ์ (Layer Height) | 0.16 - 0.20 มม. | ให้ความเรียบเนียนของร่องเขี้ยว Labyrinth และเกลียวยึดน็อต |
| อุณหภูมิหัวฉีด (Nozzle Temperature) | 235°C - 245°C | ให้การยึดเกาะระหว่างชั้น (Inter-layer Adhesion) แนบแน่น ปราศจากตามด |
| อุณหภูมิฐานพิมพ์ (Bed Temperature) | 75°C - 80°C | ป้องกันปัญหาชิ้นงานโก่งงอ (Anti-warping) บริเวณมุมกล่อง |
| การปรับสภาพผิวภายใน (Surface Finish) | เคลือบสีดำด้าน (Ultra-flat Matt Black) | ขจัดแสงสะท้อนภายในกล่อง (Internal Stray Light) ให้ต่ำกว่าร้อยละ 1 |

## 5. แผนผังทางเดินแสงและการป้องกันแสงรบกวน (Optical Ray Tracing)

```
       [ ตัวเครื่องสมาร์ทโฟน / กล้องตรวจวัด ]
                    |
          [ ปะเก็นยางโฟม EVA สีดำ ]  <--- ป้องกันแสงภายนอกรั่วเข้าเลนส์ 100%
                    |
            [ ช่องรับแสง 0 องศา ]
                    |
                    | (แนวตั้งฉาก 0° collinear)
                    | รับเฉพาะแสงสะท้อนแบบกระจาย (Diffuse Reflectance)
                    | ตัดแสงสะท้อนเงา Specular Glare สมบูรณ์
                    |
 LED Array 45° ---> | <--- NIR LED 45°
 (465, 525, 660 nm) |      (720, 850, 940 nm)
                    |
                    |  ระยะห่างโฟกัสคงที่ 50 มิลลิเมตร
                    |
      ==============|==============
     [ ผิวหน้าดินเรียบในถาดขนาด Ø 35 mm ]
     [ ลิ้นชักดักแสง Labyrinth Seal สองชั้น ]
```

## 6. ไฟล์โมเดลและการนำไปใช้งาน

* **ไฟล์ CAD ต้นฉบับ** `dark_chamber_model.scad` (สร้างไว้ในโฟลเดอร์โครงการนี้)
  * ผู้ใช้สามารถเปิดไฟล์ด้วยโปรแกรม **OpenSCAD** ซึ่งเป็นโปรแกรมฟรีแบบ Open-Source
  * สามารถปรับเปลี่ยนตัวแปรขนาดได้ตามต้องการ เช่น ความกว้างโทรศัพท์ ระยะโฟกัส หรือขนาดเซนเซอร์
  * กดปุ่ม **F5** เพื่อดูภาพจำลอง 3 มิติ
  * กดปุ่ม **F6** เพื่อเรนเดอร์ชิ้นงานเชิงเรขาคณิต (Render)
  * ไปที่เมนู `File -> Export as STL...` เพื่อบันทึกเป็นไฟล์ `.stl` สำหรับนำไปโหลดเข้าโปรแกรมเครื่องพิมพ์ 3 มิติต่อไป
* **ไฟล์แบบแปลนเวกเตอร์** `dark_chamber_blueprint.svg` แสดงแผนผังตัดขวางและมิติวิศวกรรมความละเอียดสูง สามารถเปิดดูผ่านเว็บเบราว์เซอร์หรือโปรแกรมกราฟิกได้ทันที
