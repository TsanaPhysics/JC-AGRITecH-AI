# บทที่ 3
# วิธีดำเนินการวิจัย

การวิจัยเรื่อง "การพัฒนาชุดทดสอบค่าความเป็นกรด-ด่างของดินแบบพกพาภาคสนามความแม่นยำสูงด้วยการชดเชยความคลาดเคลื่อนโดยปัญญาประดิษฐ์" มีระเบียบวิธีวิจัยและขั้นตอนการดำเนินงานวิจัยที่ได้รับการออกแบบอย่างเป็นระบบ เพื่อให้ได้ชุดทดสอบที่มีความถูกต้อง แม่นยำ และมีความน่าเชื่อถือตามหลักการเคมีวิเคราะห์และวิศวกรรมคอมพิวเตอร์ โดยแบ่งวิธีดำเนินการวิจัยออกเป็น 8 ส่วนหลัก ดังนี้

3.1 การออกแบบสถาปัตยกรรมระบบฮาร์ดแวร์และวงจรอิเล็กทรอนิกส์  
3.2 การเตรียมสารละลายบัฟเฟอร์มาตรฐานและอุปกรณ์ควบคุมสภาวะแวดล้อม  
3.3 กระบวนการเก็บรวบรวมข้อมูลและการสร้างชุดข้อมูล (Dataset Acquisition Pipeline)  
3.4 การจัดการและเตรียมข้อมูล (Data Preprocessing & Splitting)  
3.5 การออกแบบและพัฒนาโครงข่ายประสาทเทียม (ANN Architecture & Model Training)  
3.6 การแปลงโมเดลสู่ระบบสมองกลฝังตัว (Edge TinyML C++ Engine Deployment)  
3.7 การประเมินประสิทธิภาพและการทดสอบความใช้ได้ของวิธี (Method Validation)  
3.8 ระเบียบวิธีการทดสอบภาคสนามในสวนผลไม้และการวิเคราะห์ทางสถิติ

## 3.1 การออกแบบสถาปัตยกรรมระบบฮาร์ดแวร์และวงจรอิเล็กทรอนิกส์

ชุดทดสอบค่า Soil pH ภาคสนามที่พัฒนาขึ้น ได้รับการออกแบบให้เป็นอุปกรณ์พกพาขนาดกะทัดรัด (Handheld Portable Unit) ที่มีหน่วยประมวลผลประสิทธิภาพสูงและเซนเซอร์มาตรฐานอุตสาหกรรมในตัว ประกอบด้วยองค์ประกอบฮาร์ดแวร์และการกำหนดขาเชื่อมต่อ (Pin Assignment) ดังนี้

### 3.1.1 แผงวงจรควบคุมหลัก ATD3.5-S3
แผงวงจรควบคุมหลักใช้บอร์ด **ATD3.5-S3** ขับเคลื่อนด้วยไมโครคอนโทรลเลอร์ **ESP32-S3-WROOM-1** ซึ่งมีคุณสมบัติทางเทคนิคดังนี้
- หน่วยประมวลผล 32-bit Xtensa dual-core LX7 ความถี่สัญญาณนาฬิกาสูงสุด 240 MHz
- รองรับชุดคำสั่งเวกเตอร์ (Vector Instructions / SIMD) เหมาะสำหรับการคำนวณโครงข่ายประสาทเทียม (Neural Network Acceleration)
- หน่วยความจำภายในประกอบด้วย 512 KB SRAM, 384 KB ROM, พร้อมหน่วยความจำภายนอก 16 MB Flash Memory และ 8 MB Octal PSRAM รองรับการเก็บโมเดล AI และบัฟเฟอร์หน้าจอความละเอียดสูง
- จอแสดงผลสีชนิด IPS ขนาด 3.5 นิ้ว ความละเอียด $480 \times 320$ พิกเซล ควบคุมด้วยไอซีไดรเวอร์ ST7796 ผ่านอินเทอร์เฟซขนาน 8-bit หรือ SPI ความเร็วสูง และระบบสัมผัส Capacitive Touch FT6336 ผ่าน I2C Bus

## 3.2 การเตรียมสารละลายบัฟเฟอร์มาตรฐานและอุปกรณ์ควบคุมสภาวะแวดล้อม

### 3.2.1 การเตรียมสารละลายบัฟเฟอร์มาตรฐานอ้างอิง
คณะผู้วิจัยได้จัดเตรียมสารละลายบัฟเฟอร์มาตรฐานที่ผ่านการรับรองมาตรฐานสากลและสามารถสอบกลับได้ตามมาตรฐาน NIST (NIST-traceable Standard Buffer Solutions) จำนวน 3 ระดับค่า pH ดังนี้
1. **สารละลายบัฟเฟอร์มาตรฐานกรด:** สารละลาย Potassium hydrogen phthalate ค่า pH เท่ากับ **4.01 ที่ 25.0 องศาเซลเซียส**
2. **สารละลายบัฟเฟอร์มาตรฐานกลาง:** สารละลายผสม Potassium dihydrogen phosphate และ Disodium hydrogen phosphate ค่า pH เท่ากับ **7.00 ที่ 25.0 องศาเซลเซียส**
3. **สารละลายบัฟเฟอร์มาตรฐานเบส:** สารละลายผสม Sodium carbonate และ Sodium hydrogen carbonate ค่า pH เท่ากับ **10.01 ที่ 25.0 องศาเซลเซียส**

สารละลายบัฟเฟอร์ทั้งหมดถูกจัดเก็บในขวดพลาสติกโพลีเอทิลีนปิดสนิท และเก็บรักษาในตู้ควบคุมอุณหภูมิที่ $25.0 \pm 1.0\,^\circ\text{C}$ ก่อนนำมาใช้งาน

### 3.2.2 อ่างควบคุมอุณหภูมิ (Precision Water Bath)
ใช้อ่างควบคุมอุณหภูมิแบบควบคุมความร้อนสม่ำเสมอพร้อมระบบหมุนเวียนน้ำ (Circulating Water Bath) สามารถปรับตั้งและควบคุมอุณหภูมิของสารละลายทดสอบได้ในช่วง **20.0 ถึง 50.0 องศาเซลเซียส** โดยมีความแม่นยำในการรักษาอุณหภูมิคงที่อยู่ที่ $\pm 0.1\,^\circ\text{C}$

### 3.2.3 เครื่องมือวัดอ้างอิงระดับห้องปฏิบัติการ (Standard Reference Instrument)
ใช้เครื่องวัด pH meter ชนิดตั้งโต๊ะเกรดเคมีวิเคราะห์ (Benchtop Precision pH Meter) ยี่ห้อ Mettler Toledo รุ่น SevenExcellence พร้อมหัววัดแก้วผสม (Combination Glass Electrode) มีความละเอียดในการแสดงผล 0.001 pH unit และผ่านการปรับเทียบมาตรฐานแบบ 3 จุด (3-point calibration) ทุกครั้งก่อนเริ่มการทดลอง

## 3.3 กระบวนการเก็บรวบรวมข้อมูลและการสร้างชุดข้อมูล (Dataset Acquisition Pipeline)

การเก็บรวบรวมข้อมูลเพื่อสร้างชุดข้อมูล (Dataset) สำหรับฝึกสอนโมเดลปัญญาประดิษฐ์ ดำเนินการผ่านระบบเก็บข้อมูลอัตโนมัติ (Automated Data Acquisition Firmware) ดังมีขั้นตอนย่อยดังนี้

### 3.3.1 โครงสร้างเฟรมคำสั่ง Modbus RTU และการตรวจสอบ CRC-16
การอ่านค่าจากโพรบวัดดินส่งคำสั่ง Request Frame ผ่านโปรโตคอล Modbus RTU ดังแสดงในตารางที่ 3.2

**ตารางที่ 3.2 โครงสร้างเฟรมข้อมูล Modbus RTU สำหรับอ่านค่าพารามิเตอร์ดิน**

| ไบต์ที่ (Byte Offset) | ชื่อฟิลด์ (Field Name) | ค่าฐานสิบหก (Hex Value) | คำอธิบาย |
| :---: | :--- | :---: | :--- |
| 1 | Slave Address | `0x01` | แอดเดรสของโพรบวัดดิน |
| 2 | Function Code | `0x03` | ฟังก์ชันอ่านค่า Holding Registers |
| 3 - 4 | Starting Address | `0x00 0x00` | ตำแหน่งรีจิสเตอร์เริ่มต้น (ความชื้น, อุณหภูมิ, EC, pH, N, P, K) |
| 5 - 6 | Number of Points | `0x00 0x07` | จำนวนรีจิสเตอร์ที่ต้องการอ่าน (7 รีจิสเตอร์ = 14 ไบต์) |
| 7 - 8 | CRC-16 Checksum | `0x04 0x08` | รหัสตรวจสอบความถูกต้อง CRC-16 Modbus (LSB, MSB) |

รหัสตรวจสอบความผิดพลาดคำนวณตามอัลกอริทึม **CRC-16 Modbus (Generating Polynomial 0xA001)** ในเฟิร์มแวร์ C++:

```cpp
uint16_t calculateCRC16(const uint8_t *buf, uint16_t len) {
    uint16_t crc = 0xFFFF;
    for (uint16_t pos = 0; pos < len; pos++) {
        crc ^= (uint16_t)buf[pos];
        for (int i = 8; i != 0; i--) {
            if ((crc & 0x0001) != 0) {
                crc >>= 1;
                crc ^= 0xA001;
            } else {
                crc >>= 1;
            }
        }
    }
    return crc;
}
```

### 3.3.2 ขั้นตอนการทดลองเก็บข้อมูลในห้องปฏิบัติการ
1. นำโพรบวัดดิน 7-in-1 และหัววัดอุณหภูมิ SHT45 จุ่มลงในสารละลายบัฟเฟอร์มาตรฐานชุดแรก (บัฟเฟอร์ pH 4.01) ในอ่างควบคุมอุณหภูมิ
2. เริ่มต้นควบคุมอุณหภูมิของสารละลายที่ $20.0\,^\circ\text{C}$ รอจนกระทั่งระบบเข้าสู่สมดุลทางความร้อนและเคมีไฟฟ้าเป็นเวลา 3 นาที
3. บันทึกข้อมูลสัญญาณดิบของเซนเซอร์ ($E_{\text{raw}}$), ค่าอุณหภูมิ ($T$), ค่าสภาพนำไฟฟ้า (EC), และค่า pH มาตรฐาน ($pH_{\text{standard}}$) อย่างต่อเนื่องเป็นเวลา 2 นาที ด้วยความถี่ 1 Hz (ได้ข้อมูล 120 เวกเตอร์ต่ออุณหภูมิ)
4. ปรับเพิ่มอุณหภูมิของอ่างน้ำเป็น $25.0, 30.0, 35.0, 40.0, 45.0$ และ $50.0\,^\circ\text{C}$ ตามลำดับ โดยทำซ้ำกระบวนการบันทึกข้อมูลในทุกระดับอุณหภูมิ
5. ล้างทำความสะอาดโพรบด้วยน้ำปราศจากไอออน (Deionized Water) ซับให้แห้งด้วยกระดาษไร้ขุย แล้วนำไปทำซ้ำกระบวนการเดิมกับสารละลายบัฟเฟอร์ pH 7.00 และ pH 10.01 จนครบถ้วน ได้ชุดข้อมูลรวมทั้งสิ้น 2,520 ตัวอย่าง

ชุดการทดลองเก็บรวบรวมข้อมูลในห้องปฏิบัติการเคมีวิเคราะห์และการควบคุมอุณหภูมิแสดงดังภาพที่ 3.7

## 3.4 การจัดการและเตรียมข้อมูล (Data Preprocessing & Splitting)

ก่อนนำชุดข้อมูลเข้าสู่กระบวนการฝึกสอนโมเดลปัญญาประดิษฐ์ คณะผู้วิจัยได้ดำเนินการเตรียมข้อมูลตามขั้นตอนมาตรฐาน ดังนี้

### 3.4.1 การตรวจสอบและกำจัดข้อมูลผิดปกติ (Data Cleaning & Outlier Removal)
ตรวจสอบการกระจายตัวของข้อมูลด้วยแผนภาพกล่อง (Box Plot) และใช้วิธี Interquartile Range (IQR) เพื่อกำจัดข้อมูลที่มีสัญญาณผิดปกติอันเกิดจากความไม่เสถียรของอุณหภูมิในช่วงเริ่มเปลี่ยนระดับความร้อน โดยกำหนดช่วงข้อมูลปกติให้อยู่ระหว่าง $[Q_1 - 1.5\text{IQR}, Q_3 + 1.5\text{IQR}]$

### 3.4.2 การปรับมาตราส่วนข้อมูล (Feature Scaling)
เนื่องจากตัวแปรอินพุตมีหน่วยและช่วงของค่าที่แตกต่างกันอย่างมาก จึงทำการปรับค่าให้อยู่ในช่วงมาตรฐาน $[0, 1]$ ด้วยวิธี Min-Max Normalization:

$$x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

### 3.4.3 การแบ่งชุดข้อมูล (Data Splitting)
ชุดข้อมูลที่ผ่านการทำความสะอาดแล้ว จะถูกสุ่มแบ่งแบบแบ่งชั้น (Stratified Random Split) ออกเป็น 3 ส่วนอิสระจากกัน:
1. **ชุดข้อมูลสำหรับฝึกสอน (Training Set, 70%):** จำนวน 1,764 ตัวอย่าง ใช้สำหรับปรับค่าน้ำหนัก (Weights) และค่าไบแอส (Biases) ในโครงข่ายประสาทเทียม
2. **ชุดข้อมูลสำหรับตรวจสอบ (Validation Set, 15%):** จำนวน 378 ตัวอย่าง ใช้สำหรับปรับจูนไฮเปอร์พารามิเตอร์และตรวจสอบการเรียนรู้ในแต่ละ Epoch เพื่อป้องกันการเกิด Overfitting
3. **ชุดข้อมูลสำหรับทดสอบ (Test Set, 15%):** จำนวน 378 ตัวอย่าง เป็นข้อมูลที่โมเดลไม่เคยเห็นมาก่อน ใช้สำหรับประเมินประสิทธิภาพครั้งสุดท้าย

## 3.5 การออกแบบและพัฒนาโครงข่ายประสาทเทียม (ANN / MLP Architecture)

### 3.5.1 โครงสร้างสถาปัตยกรรมโครงข่ายประสาทเทียม
สถาปัตยกรรมโมเดลที่ได้รับการออกแบบและคัดเลือก คือ โครงข่ายประสาทเทียมแบบเพอร์เซปตรอนหลายชั้น (Multilayer Perceptron หรือ MLP) โดยมีโครงสร้างทางคณิตศาสตร์ดังนี้
- **Input Layer ($l=0$):** จำนวน 3 โหนด รับค่าอินพุตมาตรฐาน $\mathbf{x} = [E_{\text{norm}}, T_{\text{norm}}, \text{EC}_{\text{norm}}]^T$
- **Hidden Layer 1 ($l=1$):** จำนวน 16 โหนด ใช้ฟังก์ชันกระตุ้นชนิด **ReLU** ($f(z) = \max(0, z)$):
  $$\mathbf{z}^{[1]} = \mathbf{W}^{[1]} \mathbf{x} + \mathbf{b}^{[1]}$$
  $$\mathbf{a}^{[1]} = \text{ReLU}(\mathbf{z}^{[1]})$$
- **Hidden Layer 2 ($l=2$):** จำนวน 8 โหนด ใช้ฟังก์ชันกระตุ้นชนิด **ReLU**:
  $$\mathbf{z}^{[2]} = \mathbf{W}^{[2]} \mathbf{a}^{[1]} + \mathbf{b}^{[2]}$$
  $$\mathbf{a}^{[2]} = \text{ReLU}(\mathbf{z}^{[2]})$$
- **Output Layer ($l=3$):** จำนวน 1 โหนด ใช้ฟังก์ชันกระตุ้นแบบ **Linear** ($f(z) = z$) ให้ค่าผลลัพธ์คือ $\text{pH}_{\text{predicted}}$:
  $$\hat{y} = \mathbf{W}^{[3]} \mathbf{a}^{[2]} + b^{[3]}$$

### 3.5.2 พารามิเตอร์การฝึกสอนโมเดล (Hyperparameters)
- **Optimizer:** Adam (Adaptive Moment Estimation) ด้วยค่า Learning Rate $\eta = 0.001$, $\beta_1 = 0.9$, $\beta_2 = 0.999$
- **Loss Function:** Mean Squared Error (MSE)
- **Batch Size:** 32 ตัวอย่าง
- **Epochs:** สูงสุด 500 รอบการฝึกสอน
- **Regularization:** ใช้ Early Stopping โดยหยุดการฝึกสอนเมื่อค่า Loss ของ Validation Set ไม่ลดลงติดต่อกัน 25 Epochs พร้อมบันทึกค่าน้ำหนักที่ดีที่สุด

## 3.6 การแปลงโมเดลสู่ระบบสมองกลฝังตัว (Edge TinyML C++ Engine Deployment)

เพื่อนำโมเดลปัญญาประดิษฐ์ไปประมวลผลบนไมโครคอนโทรลเลอร์ ESP32-S3 ในภาคสนามได้อย่างสมบูรณ์ คณะผู้วิจัยได้พัฒนากระบวนการแปลงโมเดลสู่ภาษา C++ (TinyML Deployment):

1. **การสกัดค่าน้ำหนัก (Weight Extraction):** สกัดค่าน้ำหนักเชื่อมโยง (Weight Matrices: $\mathbf{W}_1, \mathbf{W}_2, \mathbf{W}_3$) และเวกเตอร์ไบแอส ($\mathbf{b}_1, \mathbf{b}_2, \mathbf{b}_3$) จากโมเดลที่ฝึกสอนสมบูรณ์แล้ว
2. **การแปลงเป็น Static C++ Array:** แปลงค่าน้ำหนักให้อยู่ในรูปตัวแปรคงที่แบบ `const float` จัดเก็บไว้ในหน่วยความจำโปรแกรม (Flash ROM) ของ ESP32-S3
3. **การสร้างฟังก์ชันคำนวณแบบ Forward Pass:** เขียนอัลกอริทึมการคูณเมทริกซ์และเวกเตอร์ (Matrix-Vector Multiplication) และฟังก์ชัน ReLU เป็นภาษา C++ ภายในโมดูล `TinyML_PHEngine`
4. **โครงสร้างการชดเชยสองขั้นตอน (Two-Stage Decoupling Architecture):**
   - **ขั้นตอนที่ 1 (Physical Compensation):** คำนวณค่า pH พื้นฐานตามทฤษฎีสมการเนิร์นสต์ร่วมกับค่าอุณหภูมิวัดจริง $T$
   - **ขั้นตอนที่ 2 (AI Residual Error Compensation):** ส่งค่าผลลัพธ์พร้อมสัญญาณดิบเข้าสู่โมเดล TinyML ANN เพื่อชดเชยค่าความไม่เป็นเชิงเส้นและค่าเลื่อนลอยที่เหลือ (Residual Non-linearities)

```cpp
// โครงสร้างฟังก์ชัน C++ Inference Engine บน ESP32-S3
float predictSoilPH(float rawEMF, float tempC, float ec) {
    // 1. Min-Max Normalization
    float norm_e  = (rawEMF - E_MIN) / (E_MAX - E_MIN);
    float norm_t  = (tempC  - T_MIN) / (T_MAX - T_MIN);
    float norm_ec = (ec     - EC_MIN) / (EC_MAX - EC_MIN);

    // 2. Hidden Layer 1 (16 nodes with ReLU)
    float h1[16];
    for (int j = 0; j < 16; j++) {
        float sum = b1[j] + norm_e * w1[0][j] + norm_t * w1[1][j] + norm_ec * w1[2][j];
        h1[j] = (sum > 0.0f) ? sum : 0.0f; // ReLU
    }

    // 3. Hidden Layer 2 (8 nodes with ReLU)
    float h2[8];
    for (int k = 0; k < 8; k++) {
        float sum = b2[k];
        for (int j = 0; j < 16; j++) sum += h1[j] * w2[j][k];
        h2[k] = (sum > 0.0f) ? sum : 0.0f; // ReLU
    }

    // 4. Output Layer (Linear)
    float ph_pred = b3[0];
    for (int k = 0; k < 8; k++) ph_pred += h2[k] * w3[k][0];

    // 5. Denormalization to pH Unit (0 - 14)
    return ph_pred * (PH_MAX - PH_MIN) + PH_MIN;
}
```

## 3.7 การประเมินประสิทธิภาพและการทดสอบความใช้ได้ของวิธี (Method Validation)

การประเมินคุณภาพและความน่าเชื่อถือของชุดทดสอบที่พัฒนาขึ้น ดำเนินการตามแนวทางมาตรฐานการตรวจสอบความใช้ได้ของวิธีเคมีวิเคราะห์ (EURACHEM / CITAC Guidelines) ดังนี้

### 3.7.1 การทดสอบความแม่น (Accuracy / Bias)
ทดสอบโดยนำชุดทดสอบไปวัดค่า pH ในสารละลายบัฟเฟอร์มาตรฐาน (pH 4.01, 7.00, 10.01) ที่อุณหภูมิต่างๆ เปรียบเทียบกับค่าจริงของสารละลายบัฟเฟอร์ แล้วคำนวณค่าร้อยละความคลาดเคลื่อน (Bias):

$$\text{Bias (\%)} = \left|\frac{\overline{\text{pH}}_{\text{measured}} - \text{pH}_{\text{standard}}}{\text{pH}_{\text{standard}}}\right| \times 100\%$$

**เกณฑ์การยอมรับ:** ค่าร้อยละความคลาดเคลื่อน (Bias) ต้องน้อยกว่าร้อยละ 5.0

### 3.7.2 การทดสอบความเที่ยง (Precision / %RSD)
ทดสอบความสามารถในการให้ผลซ้ำ โดยนำชุดทดสอบไปวัดค่าในสารละลายบัฟเฟอร์มาตรฐานซ้ำกัน 11 ครั้ง ($n = 11$) ภายใต้สภาวะเดียวกัน แล้วคำนวณค่าเบี่ยงเบนมาตรฐานสัมพัทธ์ (%RSD):

$$\% \text{RSD} = \left(\frac{s}{\overline{\text{pH}}}\right) \times 100\%$$

โดยที่ $s$ คือ ส่วนเบี่ยงเบนมาตรฐาน (Standard Deviation) และ $\overline{\text{pH}}$ คือ ค่าเฉลี่ยของการวัด  
**เกณฑ์การยอมรับ:** ค่า %RSD ต้องน้อยกว่าร้อยละ 5.0

### 3.7.3 ตัวชี้วัดประสิทธิภาพของโมเดลปัญญาประดิษฐ์
- **Root Mean Square Error (RMSE):**
  $$\text{RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^N \left(\text{pH}_{\text{standard}, i} - \text{pH}_{\text{pred}, i}\right)^2}$$
- **Mean Absolute Error (MAE):**
  $$\text{MAE} = \frac{1}{N}\sum_{i=1}^N \left|\text{pH}_{\text{standard}, i} - \text{pH}_{\text{pred}, i}\right|$$
- **Coefficient of Determination ($R^2$):**
  $$R^2 = 1 - \frac{\sum_{i=1}^N (\text{pH}_{\text{standard}, i} - \text{pH}_{\text{pred}, i})^2}{\sum_{i=1}^N (\text{pH}_{\text{standard}, i} - \overline{\text{pH}}_{\text{standard}})^2}$$

## 3.8 ระเบียบวิธีการทดสอบภาคสนามในสวนผลไม้และการวิเคราะห์ทางสถิติ

### 3.8.1 การเก็บตัวอย่างดินจริงในแปลงสวนทุเรียน
ดำเนินการเก็บตัวอย่างดินในแปลงปลูกทุเรียนตัวแทน 3 อำเภอในจังหวัดจันทบุรีและตราด ได้แก่
1. อำเภอมะขาม จังหวัดจันทบุรี (ดินร่วนปนทราย/ดินดาน)
2. อำเภอท่าใหม่ จังหวัดจันทบุรี (ดินร่วนเหนียวสีแดง)
3. อำเภอเขาสมิง จังหวัดตราด (ดินร่วนปนดินเหนียว)

เก็บตัวอย่างดินที่ระดับความลึก $15 - 30$ เซนติเมตร (ระดับความลึกของรากหาอาหารทุเรียน) รวมจำนวน 30 แปลงตัวแทน โดยในแต่ละจุดตัวอย่าง ดำเนินการแบ่งตัวอย่างออกเป็น 2 ส่วนเท่าๆ กัน:
- **ส่วนที่ 1:** วัดค่าทันทีในแปลงด้วยชุดทดสอบพกพาภาคสนามปัญญาประดิษฐ์ที่พัฒนาขึ้น โดยปักโพรบลงในดินที่ผสมน้ำสะอาดตามอัตราส่วน 1:1 และอ่านผลผ่านหน้าจอ Cyber Dashboard
- **ส่วนที่ 2:** บรรจุใส่ถุงพลาสติกปิดสนิท นำส่งห้องปฏิบัติการมาตรฐานเพื่ออบแห้ง บด ร่อน และตรวจวัดค่า pH ด้วยเครื่องวัดมาตรฐาน Mettler Toledo SevenExcellence (Method 1:1 Soil-to-Water Suspension)

### 3.8.2 การวิเคราะห์ผลเปรียบเทียบทางสถิติ (Statistical Analysis)
นำผลการวัดค่า Soil pH จากชุดทดสอบที่พัฒนาขึ้น มาเปรียบเทียบกับค่าวิเคราะห์มาตรฐานจากห้องปฏิบัติการ โดยทำการวิเคราะห์ข้อมูลดังนี้
1. การทดสอบการแจกแจงแบบปกติ (Normality Test) ด้วย Shapiro-Wilk Test
2. การทดสอบความแตกต่างของค่าเฉลี่ยคู่ตัวอย่างด้วย **Paired Samples t-test** ที่ระดับนัยสำคัญ $\alpha = 0.05$ (หาก $p > 0.05$ แสดงว่าไม่มีความแตกต่างอย่างมีนัยสำคัญทางสถิติ)
3. การวิเคราะห์ความสัมพันธ์เชิงเส้น (Linear Regression Analysis) และแผนภาพความสอดคล้อง Bland-Altman Plot เพื่อประเมินขอบเขตของความสอดคล้อง (Limits of Agreement: LoA)
