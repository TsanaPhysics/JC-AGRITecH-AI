# คลังข้อมูลโครงการวิจัยและสารบบผู้ช่วยวิจัยหลัก (Research Project Dossier & Lead Assistant Archive)

**โครงการวิจัย** การพัฒนาชุดทดสอบค่าความเป็นกรด-ด่างของดินแบบพกพาภาคสนามความแม่นยำสูงด้วยการชดเชยความคลาดเคลื่อนโดยปัญญาประดิษฐ์  
**คณะผู้วิจัย**  
1. **อาจารย์ธนพัฒน์ ถิระวุฒิ** (หัวหน้าโครงการ สัดส่วน 50%)  
2. **ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา** (ผู้ร่วมวิจัย สัดส่วน 30%)  
3. **ผู้ช่วยศาสตราจารย์ ดร.นันทพร มูลรังษี** (ผู้ร่วมวิจัย สัดส่วน 10%)  
4. **รองศาสตราจารย์ ดร.นิภัทร เปี่ยมอรุณ** (ผู้ร่วมวิจัย สัดส่วน 10%)  
**หน่วยงาน** คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี  
**งบประมาณ** 75,000 บาท กองทุนวิจัย มหาวิทยาลัยราชภัฏรำไพพรรณี ประจำปีงบประมาณ พ.ศ. 2569

## 1. วัตถุประสงค์ของโฟลเดอร์นี้

โฟลเดอร์นี้จัดทำขึ้นเพื่อเป็นคลังข้อมูลศูนย์กลาง (Single Source of Truth) สำหรับการถอดรหัสข้อเสนอโครงการวิจัยฉบับเต็ม (Full Proposal 26 หน้า) โดยทำหน้าที่เป็นคลังข้อมูลอ้างอิงให้แก่ **ผู้ช่วยวิจัยหลัก (Lead Research Assistant)** ในการปฏิบัติงาน 3 ด้านหลัก

1. **การปรับปรุง ยกร่าง และขยายรายงานวิจัยฉบับสมบูรณ์** ในโฟลเดอร์ `/Users/chewathassana/Desktop/handysense/thanapat_research/` (บทที่ 1 ถึง 5)
2. **การพัฒนาและปรับปรุงโค้ดโปรแกรมแอปพลิเคชันมือถือ** ในแอปพลิเคชันตรวจวัดค่า pH ดิน (Flutter / Dart เช่น วิดเจ็ต `ht_compensation_card.dart` ใน `SoilpH_HT`)
3. **การพัฒนาแบบจำลองปัญญาประดิษฐ์ชดเชยความคลาดเคลื่อน** ทั้งในระดับการฝึกสอนด้วย Python (Scikit-Learn / PyTorch) และการแปลงสู่ระบบสมองกลฝังตัวระดับ Edge (ESP32 C++ / TinyML)
