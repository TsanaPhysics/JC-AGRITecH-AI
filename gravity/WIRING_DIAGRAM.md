# แผนผังการต่อสายวงจรเซนเซอร์เกษตรกรรม (Sensor Wiring Diagram)
### สำหรับบอร์ดควบคุม ATD3.5-S3 และ ATD3.5-S3 Farm1 Shield

---

## 1. ภาพรวมการเชื่อมต่อระบบ

```

                         +-----------------+-----------------+
                                           | เสียบประกบตรงขา
                         +-----------------v-----------------+
                         |      ATD3.5-S3 Farm1 Shield       |
                         |  (จุดต่อ I2C, Analog, RS485, 12V)  |

                            |            |            |
             +--------------+            |            +---------------+
             |                           |                            |
```

## 2. ตารางการต่อสายเซนเซอร์แต่ละตัว (เทียบจากรูปถ่ายจริง)

### 2.1 เซนเซอร์อุณหภูมิและความชื้นอากาศ SHT45 (โพรบกรองโลหะ Sintered Metal)
*โปรโตคอล:* **I2C Bus (Address: 0x44)**
*แรงดันไฟเลี้ยง:* **3.3V**

| สีสายไฟของเซนเซอร์ | ฟังก์ชันสัญญาณ | จุดต่อบนบอร์ด Farm1 Shield / ATD3.5-S3 | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| **สีแดง (Red)** | VCC | **3V3** | ไฟเลี้ยง 3.3V |
| **สีดำ (Black)** | GND | **GND** | กราวด์ร่วม |
| **สีเขียว (Green)** | SCL (Clock) | **SCL (GPIO8)** | ขาที่ 3 ของช่อง I2C |
| **สีเหลือง (Yellow)** | SDA (Data) | **SDA (GPIO9)** | ขาที่ 4 ของช่อง I2C |

---

### 2.2 เซนเซอร์วัดความเข้มแสงกันน้ำ "โดมตะวัน" (Dome Light Sensor)
*โปรโตคอล:* **I2C Bus (ชิป BH1750, Address: 0x23)**
*แรงดันไฟเลี้ยง:* **3.3V หรือ 5V**

| สีสายไฟของเซนเซอร์ | ฟังก์ชันสัญญาณ | จุดต่อบนบอร์ด Farm1 Shield / ATD3.5-S3 | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| **สีแดง (Red)** | VCC | **3V3 หรือ 5V** | ไฟเลี้ยง |
| **สีดำ (Black)** | GND | **GND** | กราวด์ร่วม |
| **สีเขียว (Green)** | SCL (Clock) | **SCL (GPIO8)** | พ่วงต่อขนานร่วมกับขา SCL ของ SHT45 |
| **สีเหลือง/ขาว** | SDA (Data) | **SDA (GPIO9)** | พ่วงต่อขนานร่วมกับขา SDA ของ SHT45 |

> **หมายเหตุ I2C Bus Sharing:** เซนเซอร์ SHT45 (Addr `0x44`) และ โดมตะวัน BH1750 (Addr `0x23`) ใช้ I2C Address ไม่ซ้ำกัน จึงต่อสายขนานเข้าบัส I2C เดียวกันได้อย่างสมบูรณ์ โดยโปรแกรมกำหนด `SDA=GPIO9 (สายเหลือง)` และ `SCL=GPIO8 (สายเขียว)` ตามการต่อสายจริงบนเทอร์มินัลบล็อก Farm1 Shield

---

### 2.3 เซนเซอร์วัดความชื้นในดิน "Soil Stick เกษตรไทย IoT" (สายสีเทา)
*โปรโตคอล:* **Analog Voltage (0 - 3.0V DC)**
*แรงดันไฟเลี้ยง:* **3.3V**
*หลักการวัด:* ความจุไฟฟ้า (Capacitive) ปราศจากการกัดกร่อนของขั้วโลหะ

| สีสายไฟของเซนเซอร์ | ฟังก์ชันสัญญาณ | จุดต่อบนบอร์ด Farm1 Shield | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| **สีแดง (Red)** | VCC | **3V3** | ไฟเลี้ยงวงจรออสซิลเลเตอร์ในโพรบ |
| **สีดำ (Black)** | GND | **GND** | กราวด์ร่วม |
| **สีน้ำเงิน/เหลือง** | Signal (Vout) | **A1 (GPIO1)** | สัญญาณแรงดันอนาล็อกเข้าช่อง ADC A1 |

---

### 2.4 เซนเซอร์คุณสมบัติดินรอบด้าน (Soil Multi-parameter 7-in-1)
*รหัสรุ่นอุปกรณ์:* **`SN-3002-TR-ECTHNPKPH-N01`** (Moisture, Temp, EC, pH, N, P, K)  
*โปรโตคอล:* **RS485 Modbus RTU** (Baudrate: **4800 bps** (ค่ามาตรฐานโรงงาน) หรือ 9600 bps, Data bits: 8, Parity: None, Stop bit: 1)  
*แรงดันไฟเลี้ยง:* **5 - 30V DC** (แนะนำ **12V DC** จากแจ็คไฟบอร์ด Farm1 Shield)  

| สีสายไฟของเซนเซอร์ | สัญลักษณ์ | ฟังก์ชันการทำงาน | จุดต่อบนบอร์ด Farm1 Shield / ATD3.5-S3 | คำแนะนำ |
| :--- | :---: | :--- | :--- | :--- |
| **สีน้ำตาล (Brown)** | **VCC** | ขั้วไฟเลี้ยงบวก (+5V ถึง +30V DC) | **ขั้ว 12V / VIN Terminal** | ดึงไฟเลี้ยง 12V DC มาจากอะแดปเตอร์ของ Farm1 Shield |
| **สีดำ (Black)** | **GND** | ขั้วกราวด์ไฟเลี้ยง (-) | **ขั้ว GND Terminal** | กราวด์ร่วมของระบบ |
| **สีเหลือง (Yellow)** | **485-A** | สัญญาณข้อมูล RS485 (Data + / A) | **ขั้วต่อ RS485 ช่อง A** | ต่อเข้าขั้ว A (เชื่อมต่อภายในกับขา TX: GPIO40) |
| **สีน้ำเงิน (Blue)** | **485-B** | สัญญาณข้อมูล RS485 (Data - / B) | **ขั้วต่อ RS485 ช่อง B** | ต่อเข้าขั้ว B (เชื่อมต่อภายในกับขา RX: GPIO41) |

> ⚠️ **ข้อควรระวังสำคัญมาก:**  
> 1. **ห้ามต่อสายสีน้ำตาล (12V) เข้าช่องอื่นโดยเด็ดขาด** เพราะจะทำให้บอร์ดควบคุมเสียหายทันที  
> 2. สัญญาณ RS485 ใช้คู่สาย **เหลือง (A)** และ **น้ำเงิน (B)** หากเปิดระบบแล้วอ่านค่าไม่ได้ หรือ Error Count เพิ่มขึ้น ให้ลองสลับคู่สาย A และ B สลับกัน

## 3. ผัง Modbus RTU Register Map (เซนเซอร์ 7-in-1 ดิน)

คำสั่งอ่านค่า: **Function Code 0x03 (Read Holding Registers)**

| Register Address | พารามิเตอร์ | หน่วย | Scale Factor / การแปลงค่า | ตัวอย่างค่าดิบ | ค่าจริงที่ได้ |
| :---: | :--- | :---: | :---: | :---: | :---: |
| `0x0000` | ความชื้นในดิน (Soil Moisture) | % | หาร 10 | `452` | 45.2 % |
| `0x0001` | อุณหภูมิดิน (Soil Temp) | °C | หาร 10 (signed) | `285` | 28.5 °C |
| `0x0002` | การนำไฟฟ้า/ความเค็ม (Soil EC) | µS/cm | ค่าดิบ (1:1) | `750` | 750 µS/cm |
| `0x0003` | ความเป็นกรด-ด่าง (Soil pH) | pH | หาร 10 หรือ 100 | `68` / `680` | 6.80 pH |
| `0x0004` | ไนโตรเจน (Nitrogen - N) | mg/kg | ค่าดิบ (1:1) | `35` | 35 mg/kg |
| `0x0005` | ฟอสฟอรัส (Phosphorus - P) | mg/kg | ค่าดิบ (1:1) | `18` | 18 mg/kg |
| `0x0006` | โพแทสเซียม (Potassium - K) | mg/kg | ค่าดิบ (1:1) | `120` | 120 mg/kg |

## 4. ข้อควรระวังในการติดตั้งภาคสนาม (Field Deployment Best Practices)

1. **การจ่ายไฟ:** ต้องเสียบอะแดปเตอร์ 12V 2A เข้าที่ Farm1 Shield ทุกครั้ง เนื่องจากเซนเซอร์ RS485 7-in-1 ต้องการแรงดันไฟเลี้ยงขั้นต่ำ 5-12V (ไฟจากช่อง USB ไม่เพียงพอสำหรับขับโพรบ RS485 และรีเลย์)
2. **การปักโพรบดิน:**
   - **Soil Stick:** ปักลงดินให้ส่วนแผ่นวงจรสีเขียวมิดดิน แต่อย่าให้ขั้วต่อสายสีเทาจมน้ำขัง
   - **7-in-1 Probe:** ปักเข็มสเตนเลสทั้ง 3 เข็มลงในดินตรงๆ จนสุดด้ามสีดำ อย่าขยับโยกไปมาเพื่อป้องกันช่องว่างอากาศรอบเข็ม ซึ่งจะทำให้ค่า EC และ NPK เพี้ยน
3. **การป้องกันสัญญาณรบกวน:** สำหรับสายสัญญาณ RS485 และ I2C ที่เดินยาวเกิน 3 เมตร แนะนำให้ใช้สายตีเกลียวมีชิลด์ (Shielded Twisted Pair) และต่อชีลด์ลง Ground ฝั่งตู้ควบคุมเพียงจุดเดียว (Single-point Grounding)
